# Tracking Antimicrobial Resistant Organisms Timely (TAROT) for methicillin-resistant *Staphylococcus aureus* (TAROT-MRSA)

![Tracking Antimicrobial Resistant Organisms Timely](TAROT_logo.jpg)


# About TAROT
TAROT is a concept for performing successive and on-demand core-genome single nucleotide polymorphism (cgSNP)-based phylogenetic analysis using whole-genome sequencing of bacterial strains. It aims to support the improvement of infection prevention and control intervention in hospitals. We have developed and validated a bioinformatics pipeline for executing TAROT analyses.

# Intended Use
Sequence read data generated by Oxford Nanopore Technologies (ONT) sequencers can be used with this pipeline to analyze MRSA strains.

# Requirements
You need to use a computer with an x86 or x64 CPU architecture. Using a computer with ARM CPU architecture may cause issues when pulling the Docker image of the tarot-mrsa-env.  


# Run TAROT-MRSA (Snakemake + Conda)

This pipeline uses a lightweight Docker container and manages tool dependencies via Conda environments.

### 1. Build Docker Image

```bash
docker build -t tarot-mrsa .
```

### 2. Prepare Data

1. Place MRSA strain sequence data (ONT v14 / Flow Cell R10.4.1) into `seq_data/<sample_id>/` directories.
2. Ensure you have the `reference_genome` directory ready (e.g., `./ref`).
3. Ensure you have the `src` scripts directory (for `remove_rec_from_ClonalFrameML...` script) ready (e.g., `./src`).

### 3. Run

Launch the Docker container with volume mounts. **Mount the `results` directory to persist outputs.**

```bash
docker run --rm -it \
  -v $(pwd)/seq_data:/tmp/seq_data \
  -v $(pwd)/ref:/tmp/Saureus_reference_strain_genome \
  -v $(pwd)/src:/tmp/program \
  -v $(pwd)/results:/tmp/results \
  tarot-mrsa bash
```

Inside the container, run the workflow with `--use-conda`:

```bash
# Per-sample processing (QC, filtering, mapping)
# Note: First run will take time to download and install Conda environments.
snakemake -s /tmp/workflow/Snakefile --configfile /tmp/config/config.yaml --use-conda --cores 16

# Full cgSNP analysis (requires ≥4 strains of the same ST)
snakemake -s /tmp/workflow/Snakefile --configfile /tmp/config/config.yaml --use-conda --cores 16 cgsnp_analysis
```

### Dry run (preview what will be executed)
```bash
snakemake -s /tmp/workflow/Snakefile --configfile /tmp/config/config.yaml --use-conda -n -p
```
